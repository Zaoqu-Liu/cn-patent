# 快速开始案例

这是一个小型虚构案例，用于在不暴露真实项目材料的情况下试用 `cn-patent`。

建议提示词：

```text
Use $cn-patent to scan examples/quickstart-case/knowledge and draft a Chinese technical disclosure.
Keep company/product names generic, run prior-art search if available, and export both Markdown and Word.
```

案例主题是自适应批任务调度组件。材料很短，但足够让 skill 完成专利点挖掘、T-P-E 链路整理和交底书起草。

## 文件

- `knowledge/architecture.md`：系统结构和关键技术细节。
- `knowledge/meeting-notes.md`：偏发明人沟通纪要的痛点和技术效果。
- `expected/minimal-disclosure.md`：用于 Word 导出 smoke test 的最小 Markdown 文档。
